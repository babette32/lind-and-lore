# Lind & Lore

The story world of Babette Lind Mendy. This is a lightweight six-page static website designed for GitHub Pages.

## Pages

- `index.html` — home
- `about.html` — author biography and short bio
- `books.html` — current and future books
- `babous-journey.html` — book detail page
- `journal.html` — low-maintenance journal landing page
- `contact.html` — accessible contact form placeholder and privacy placeholder

Shared styles, scripts, and the provisional emblem live in `assets/`. The contact and mailing-list forms are deliberately not connected to external services yet.

## Publishing

The `CNAME` file points GitHub Pages to `lindandlore.com`; `.nojekyll` allows the files to be served directly. Configure `www.lindandlore.com` for the same Pages site, and redirect `lindandlore.co.uk` to `https://lindandlore.com` at the DNS or edge provider.

## Updating later

Replace `assets/logo/lind-lore-mark.svg` with the approved final mark while retaining its filename. Author photography and final book artwork have clearly labelled visual spaces in the page markup. Connect the two forms only after a provider and privacy text are approved.
